# Hi, I am Spidy 🕸️

A clean, modern, and interactive single-page website featuring:
* **Background Video:** Muted, looping background video with a low opacity overlay to emphasize visual content.
* **Animated Entrance:** Pop-in animation for the custom character image.
* **Typing Animation:** Typewriter animation rendering `"Hi i am spidy"`.
* **Custom Web Cursor:** A custom-designed vector (SVG) spider-web cursor replacing the browser default.

## Tech Stack
* **HTML5**
* **CSS3** (Custom transitions, keyframe animations, responsive grid)
* **JavaScript** (Typewriter controller)

## How to Run
Simply open `index.html` in any web browser!
